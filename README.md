# NIS2 & BSI IT-Grundschutz Implementation Case Study

**End-to-end GRC & ISMS implementation simulation for a German Mittelstand manufacturer (BSIG/NIS2, BSI-Standards 200-2 & 200-3, ISO/IEC 27001:2022 Mapping).**

> **Disclaimer:** *Müller Maschinenbau GmbH* is a completely fictional company created for educational and portfolio purposes. All data, assets, stakeholder communications, and findings are simulated. This repository demonstrates methodological competence and does not represent a real-world audit or certification.

---

## Project Overview

This repository documents a structured, end-to-end Information Security Management System (ISMS) and Governance, Risk & Compliance (GRC) project. Acting as the **IT-Sicherheitsbeauftragter (ISB)** for a German mid-sized manufacturing company (*Mittelstand*), I manage the compliance journey from preliminary regulatory assessment under the German **NIS2 Implementation Act (BSIG)** to full technical-organizational implementation using **BSI IT-Grundschutz**.

### Key Competencies Demonstrated
- **Regulatory Analysis:** Translating BSIG/NIS2 legal obligations into operational governance.
- **BSI Methodology:** Executing *Strukturanalyse*, *Schutzbedarfsfeststellung*, *Modellierung*, *IT-Grundschutz-Check* (BSI 200-2), and *Risikoanalyse* (BSI 200-3).
- **Stakeholder & Evidence Management:** Handling incomplete information, conflicting operational priorities, and third-party vendor gaps.
- **Cross-Framework Mapping:** Bridging German BSI IT-Grundschutz controls with international **ISO/IEC 27001:2022** requirements.
