# Methodology & Framework Architecture

## 1. Regulatory vs. Implementation Frameworks
A core principle of this project is maintaining a clear boundary between **legal obligations** and **technical-organizational implementation standards**:

1. **BSIG / NIS2 (Preliminary Step):** Establishes *whether* the organization falls under statutory cybersecurity obligations (risk management, incident reporting, management accountability). **Note:** *NIS2-Betroffenheitsanalyse* is a preliminary legal/regulatory step and is **not** formally part of the BSI-Standard 200-2 sequence.
2. **BSI IT-Grundschutz (BSI-Standards 200-2 & 200-3):** Provides the structured methodology to build the ISMS, model the IT/OT environment, verify requirements, and manage risks.
3. **ISO/IEC 27001:2022 (Integration Step):** Used at the end of the project to demonstrate how BSI IT-Grundschutz artifacts map to international ISMS requirements (Clauses 4–10 and Annex A).

---

## 2. Execution Workflow

Each milestone follows a structured GRC workflow:
1. **Input & Evidence Gathering:** Reviewing simulated documentation, system inventories, and stakeholder responses (including incomplete or contradictory data).
2. **Analysis & Decision-Making:** Applying BSI/BSIG rules to classify assets, identify gaps, or evaluate risks.
3. **Documentation:** Producing concise, audit-ready tables and registers in German, paired with an English Executive Summary.
4. **Traceability:** Every finding, risk rating, and remediation action is linked back to a specific requirement (*BSI Baustein* or *BSIG* obligation) and assigned an owner.

---

## 3. Core Standards Referenced
- **BSIG (BSI-Gesetz):** German implementation of the EU NIS2 Directive.
- **BSI-Standard 200-2:** *IT-Grundschutz-Methodik* (Strukturanalyse, Schutzbedarfsfeststellung, Modellierung, IT-Grundschutz-Check).
- **BSI-Standard 200-3:** *Risikoanalyse auf der Basis von IT-Grundschutz*.
- **BSI IT-Grundschutz-Kompendium:** Modular catalog of security requirements (*Bausteine*).
- **ISO/IEC 27001:2022:** Information security management systems — Requirements.
